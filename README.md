# Manual Testing Project – Inflow Inventory Purchase Order Module

## Project Overview
This repository contains a Manual Testing project for the Inflow Inventory Purchase Order Module.

## Project Objective
The objective of this project is to verify the functionality of the Purchase Order Module by preparing test scenarios, test cases, executing them, and reporting defects.

## Modules Covered
- Discount
- Sub Total
- Taxing Scheme
- Remark
- Sticky Notes

## Testing Performed
- Functional Testing
- UI Testing
- Boundary Value Analysis (BVA)
- Equivalence Partitioning (ECP)
- Positive & Negative Testing

## Deliverables
- Test Scenarios
- Test Cases
- Bug Reports
- Screenshots
